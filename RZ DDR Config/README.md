# DDR Configuration Tool

This package includes two versions of the DDR configuration generation tool.  
Please select the appropriate version based on your VLP version.

## Available Versions

- **DDR Config Tool v3.0.2**: For use with **up to VLP v3.0.7**
- **DDR Config Tool v4.0.1**: For use with **VLP v4.0.1 or later**

## Notes

If the DDR configuration of your board differs from that of our evaluation board, you need to use the DDR config tool to generate customized DDR parameters.

> **Important:**  
> Make sure to use the DDR config tool version that matches your VLP version.  
> Using an incompatible version may result in incorrect configuration or unexpected behavior.
